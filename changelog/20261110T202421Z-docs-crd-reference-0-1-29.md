# CRD reference pages brought up to date with 0.1.29

Date: 2026-11-10T20:24:21Z

Updated the five custom-resource reference pages in `site/` from
`crates/sandbawks-types` and the generated `deploy/crds`:

- Sandbox: `pvcRetention`, `tolerations`, `nodeSelector`,
  `securityContext`, `persistenceMode`, `volumeClaimTemplates` and
  `restoreFrom`; `timeoutSeconds` described as an idle window; egress rules
  for IP/CIDR vs DNS-name entries and FQDN egress; the new status fields
  (`snapshotRunscVersion`, restart counters, `failureReason`, `failedAt`,
  `lastActivityTimestamp`, `podStatus`), failure reasons, condition types
  and the `Claimed` printer column.
- SandboxTemplate: the same scheduling, security, persistence and egress
  fields, `volumeClaimTemplatesPolicy`, and how template values reach a
  sandbox.
- SandboxWarmPool: `failed`, `total` and the mint-failure circuit breaker
  status, plus the `Failed`/`Total` printer columns.
- SnapshotJob: `targetPath` and the manifest's `runscVersion`,
  `envdCaptured`, `templateRef` and `templateImage`.
- TeamAPIKey: the required `spec.namespace`; keys live in the release
  namespace, so the example moved there.
