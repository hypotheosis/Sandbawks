## What landed

`crates/sandbawks-types/src/sandbox.rs` — the primary resource for the
controller. Group `sandbawks.io`, version `v1alpha1`, kind `Sandbox`,
plural `sandboxes`, short name `sbx`, namespaced, with the status
subresource enabled.

Types:

- `SandboxSpec` — `template_ref`, optional `runtime_class_name`,
  `resources` (`ResourceRequests` from Task 4), `timeout_seconds`,
  `auto_pause`, `env` map, opaque `metadata` map, optional
  `network_policy`. All camelCase on the wire.
- `NetworkPolicy` — `egress_allow: Vec<String>`. Empty means the
  controller-attached default-deny baseline stands unchanged.
- `SandboxPhase` — 7-state enum matching spec §5 (`Creating`,
  `Running`, `Pausing`, `Paused`, `Resuming`, `Terminating`, `Failed`).
  PascalCase on the wire. Defaults to `Creating`.
- `SandboxStatus` — observed state written by the controller:
  `phase`, `assigned_node`, `pod_ref`, `envd_address`, `snapshot_ref`,
  `last_transition_time`, `conditions`.
- `SandboxCondition` — conventional Kubernetes-style condition entry
  (`type`/`status`/`reason`/`message`/`last_transition_time`).

Print columns wired into `kubectl get sandboxes`: Phase, Template,
Runtime, Node, Age.
